How to play

  • The ✛ marker shows where to look — the question is "is there a solar installation here", not whether an outline is drawn perfectly.
  • → swipe right, click ✓, or right arrow — it's a solar panel
  • ← swipe left, click ✕, or left arrow — not a PV system
  • ↑ swipe up, click ? Unsure, or up arrow — you have a hunch but you're not sure — ambiguous, this still counts as a vote
  • a problem with the image itself (broken, obstructed, unclear)? Tap Comment to report it — doesn't count as a vote
  • made a mistake? Go back stays available until your next swipe

    What is the purpose of this game?

    PV Check is a crowdsourcing platform designed to improve OpenPVMapper.

    How it works?

    Every yes / no / unsure you swipe is one vote on a single installation. Once an installation collects 10 independent votes, we compute a consensus score from all of them — that's what turns into a label: contains PV, no PV, or ambiguous. No single swipe decides anything on its own, it's the sum of everyone's votes that does. So if you're not sure, swipe unsure rather than guessing — and a quick comment on an ambiguous case helps even more.

    Feeding back into OpenPVMapper

    Every installation in OpenPVMapper carries a tag showing where its label comes from. Today, one tag marks installations already verified through DeepPVMapper's manual annotation effort — see the Registry Audit page for how that works. Installations verified here, through crowdsourced consensus, will get their own tag in upcoming releases — raising the confidence level of the data for everyone. The first campaign focuses on the installations the model is currently least sure about.

    Building an open training dataset

    In the same spirit as the BDAPPV annotation campaign, the goal is also to build an open dataset that can be used to retrain and improve the AI models that detect solar panels in the first place — not just label what's already there.
