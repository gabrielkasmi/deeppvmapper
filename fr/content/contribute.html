Idées et questions

Discussions

Vous ne savez pas par où commencer, ou vous avez une idée ? Posez la question sur GitHub Discussions — ouvert à tous.

Questions

Une question, une idée — suggestion de fonctionnalité, « quelqu'un a-t-il déjà essayé… », retour général ? Ouvrez une discussion sur GitHub pour que la réponse reste visible pour la prochaine personne qui se pose la même question. Pour tout ce qui est plus privé — demandes de données, idées de collaboration — écrivez directement à Gabriel.

MapRoulette

Aucune compétence SIG requise

Éditer sur la carte

Aucun code requis

Le moyen le plus rapide d'améliorer le registre passe par la carte interactive : choisissez un lieu, puis survolez la zone — la carte met en évidence les détections au fur et à mesure, vous n'avez donc pas besoin de savoir à l'avance où sont les erreurs.

  • Une fausse détection ? Cliquez dessus et signalez-la.
  • Une installation manque ? Utilisez « Add installation » et dessinez son contour.
  • Un contour est faux ? Redessinez-le.

Les contributions sont relues puis intégrées aux prochaines versions du registre. Aucune installation, aucun code — juste votre connaissance locale des toitures.

PV Check

Rapide et décontracté

Une façon d'aider pendant vos minutes perdues, pensée pour le téléphone : faites défiler les détections une à une et confirmez-les ou rejetez-les, sans naviguer sur la carte — le Tinder des panneaux solaires en toiture. C'est une petite application à part, PV Check, qui tourne directement dans votre navigateur.
