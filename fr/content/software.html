Démarrage rapide

Deux façons de commencer : lancer vous-même le pipeline de détection complet, ou utiliser pypvroof seul sur des masques ou des contours que vous avez déjà.

1. Lancer le pipeline de détection complet

Clonez le dépôt et installez les dépendances. DeepPVMapper nécessite GDAL et un GPU compatible CUDA (8 Go+ de VRAM) pour exécuter classification et segmentation à grande échelle.

git clone https://github.com/gabrielkasmi/deeppvmapper.git
cd deeppvmapper
pip install -r requirements.txt

# Lancer le pipeline sur un seul département
python main.py --dpt 06

Notes d'installation complètes — GDAL, CUDA, fichiers de configuration →

2. Extraire les caractéristiques PV avec pypvroof

Vous avez déjà des masques de segmentation ou des contours de champs ? pypvroof les transforme seul en estimations de surface, d'inclinaison, d'orientation et de puissance installée — inutile de lancer tout le pipeline.

pip install pypvroof
import geojson
from pypvroof import MetadataExtraction

arrays = geojson.load(open("path/to/arrays.geojson"))
params = {
    "azimuth-method": "bounding-box",
    "tilt-method": "lut",
    "regression-type": "linear",
}
extractor = MetadataExtraction(p=params)
characteristics = extractor.extract_all_characteristics(arrays["features"][0])

Paquets

pypvroof

Un paquet Python autonome qui extrait les caractéristiques des installations PV en toiture — surface, inclinaison, orientation et puissance installée — à partir de masques de segmentation et d'emprises de bâtiments. Utilisé en interne par DeepPVMapper, et utilisable seul sur n'importe quel jeu de détections de PV en toiture.

Voir sur PyPI →

bayesian-pv-census

La méthodologie bayésienne de correction des biais derrière l'audit des registres, extraite sous forme de paquet autonome et indépendant du domaine : elle transforme des comptages imparfaits d'un détecteur — à partir d'un échantillon validé de précision/rappel — en intervalles de crédibilité a posteriori, puis vérifie si les valeurs déclarées d'un registre s'y trouvent.

Voir sur PyPI →
